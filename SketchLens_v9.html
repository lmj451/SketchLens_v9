진단 기준 가이드

모든 스케치는 같은 진단 기준표로 봅니다. 점수는 매기지 않고, 4개 항목마다 상태와 고칠 점을 알려드립니다.

진단 항목 · 점검 포인트

criteria v2_draft

항목 상태

  • 보완 필요고칠 점이 하나 이상 있음
  • 양호점검 포인트에서 뚜렷한 문제가 보이지 않음
  • 판단 불가잘림·가림·해상도 부족 등으로 점검할 수 없음

고칠 점 구성

점검 포인트 · 부위 · 문제 · 이유 · 고치는 방법

먼저 고치면 좋은 것에는 "중요" 표시가 붙고, 고민 글에 해당하는 항목의 고칠 점이 앞에 옵니다.

진단 과정

  1. 분류MobileNetV3가 어떤 옷의 스케치인지 분류합니다. 의류가 아니면 "기타"로 분류됩니다.
  2. 진단LLM이 진단 기준표의 4개 항목마다 상태와 고칠 점을 씁니다.
  3. 정리서버가 고칠 점에 우선순위를 붙이고, 로그인한 경우 작품의 새 버전으로 저장합니다.
  4. 비교수정본이면 LLM이 항목 상태 변화와 이전 고칠 점의 해결 여부를 정리합니다.

패션 스케치 확인

  • 통과의류 카테고리로 분류되고 확신도 0.8 이상
  • 다시 확인의류 카테고리지만 확신도 0.4~0.8 (화질 저하 등)
  • 거절"기타"로 분류되었거나 확신도 0.4 미만

프로토타입 안내. 실제 서비스에서는 1단계에서 학습된 MobileNetV3가 패션 스케치 여부와 의류 카테고리를 분류하고, 2단계에서 LLM이 진단 기준표의 4개 항목마다 상태와 고칠 점 · 고치는 방법을 작성합니다. 점수는 매기지 않으며, 우선순위 정리와 기록 저장은 서버가 맡습니다. 지금은 서버 연동 전이라 브라우저가 이미지의 선을 간단히 계산해 같은 형식의 데모 응답을 만들고, 로그인과 기록은 이 브라우저에만 임시로 저장합니다. 진단 내용보다 화면 흐름과 입력·출력 형식을 확인하는 용도입니다.
